# Inputs for PaperOrchestra (google-research/paper-orchestra)

Notebook 46 drafts the manuscript with PaperOrchestra's writing agents from these inputs; nothing here is paper text.

- `raw_materials/idea_sparse.md`: the research problem, hypothesis, framework and expected contributions.
- `raw_materials/experimental_log.md`: every result used in the paper, copied from `docs/RESULTS_LOG.md`, the
  preprint (arXiv:2611.13006) and the stored outputs, with their caveats. Edit this file (not the generated paper) if a
  number or a caveat should change, then run notebook 46 again.
- `template/`: ICLR 2025 style files set up as a non-anonymous preprint (author block, header "Preprint", 12-page main
  text, rules that every number must come from the log).
