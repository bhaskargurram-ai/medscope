\section*{Data and code availability}
All images come from public datasets, which are cited in Table~\ref{tab:datasets}. The copies used for training and for the main test are Kvasir-SEG from \url{https://datasets.simula.no/kvasir-seg}; HyperKvasir (\texttt{SimulaMet-HOST/HyperKvasir}), SLAKE (\texttt{BoKelvin/SLAKE}), BUSI (\texttt{MedOtter/BUSI}), ChestX-Det (\texttt{MedOtter/ChestX-Det}) and TCGA-LGG (\texttt{MedOtter/TCGA-LGG-Mask}) on Hugging Face; and SIIM-ACR from Kaggle (\path{jesperdramsch/siim-acr-pneumothorax-segmentation-data}). Because the licences of the sources differ, no image is redistributed: every test set is rebuilt from its source with the scripts of the project repository (\url{https://github.com/bhaskargurram-ai/medscope}), which also holds the code, the dated analysis plan (Supplementary Table~\ref{tab:s_plan}), the seeds, and the hardware and software versions. For the unedited pairs, the repository gives the video, clip and frame numbers of REAL-Colon and LDPolypVideo, without images; the LDPolypVideo repository states no licence. CheXpert Plus images and CheXthought annotations were used under their research-use agreements; only image identifiers and model outputs are released for them. To obtain the answers of the comparison models, test images were sent to the application programming interfaces of OpenAI, Anthropic and Google; these included REAL-Colon and LDPolypVideo frames and, for the three reference models, CheXthought test films. \toconfirm{that the CheXpert Plus research-use agreement permits sending images to these interfaces}
